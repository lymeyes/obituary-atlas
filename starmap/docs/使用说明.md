# 驾鹤集 · 群星纪年（离线星图）

把 1973–2025 年 48,980 位逝者放进一张世界星图：拉动时间轴，当期星辰依次亮起；
点击星点或名单看完整生平。和「江山时序」一样是**纯前端离线页**，`file://` 直开，
不联网、不起服务、不加载任何在线地图、不含任何 key。

## 打开

- 从 `Bookshelf/开始阅读.html` 点「驾鹤集 · 群星纪年」卡片；或
- 直接双击本目录 `index.html`（建议 Chrome / Edge / Safari；改过 JS 后按 `Cmd+Shift+R` 强刷）；
- 手机 / 平板同一份文件即可，底部切换「✦ 星图 / ☰ 名单 / ◫ 分析」三视图。

## 能做什么

| 操作 | 说明 |
|---|---|
| 拖动底部时间轴 | 年 / 月 / 日三档；当期逝者在地图上依次点亮，名单同步更新。手机端滑块与刻度已加大触控区 |
| ▶ 播放 | 自动推进；空格播放暂停，`←` `→` 逐格，`/` 聚焦搜索，`Esc` 关详情 |
| 点击星点 / 名单项 | 详情含生卒、享年、领域、地区及**可信度/依据**、死因、维基分类、别名；有正文者**按需加载完整生平**（可展开全文） |
| 领域 / 地区 / 搜索 / 仅已定位 | 组合筛选，地图与名单同步 |
| ◫ 分析 | 年代、领域、地区、死因、享年五个维度；「当期 / 全库」切换；点任意条形即反筛地图与名单，可一键清除 |
| 数据说明 | 定位覆盖率、可信度分布、依据分布、口径与限制 |
| 移动端三视图 | 底部标签栏切换；详情改为底部抽屉 + 遮罩；星图视图底部有「当期速览」，点它直达名单 |
| 地址栏深链 | `?t=2020&g=year`、`?t=2020-06&g=month`、`?t=2020-6-18&g=day`；`?p=analysis` 直接打开分析；`?id=12345` 直接打开某人 |

时间轴下方青色直方图是该时间粒度的收录人数，年份刻度按真实年份定位。

## 数据口径（重要）

| 项 | 值 |
|---|---|
| 记录数 | **48,980**（`person` 表 49,157 条，剔除 `excluded=1` 的 177 条非人物） |
| 年份跨度 | 1973–2025（51 个年份；1973 仅 1 条种子记录、1974–1975 无记录，**主体自 1976 年起**） |
| 日期精度 | 42,636 条精确到日、750 条到月、5,771 条只到年。月/日档会把精度不足者列在提示里，需切回「年」档查看，不做假造日期 |
| 地区 | **已定位 44,597 条（91.1%）**，未定位 4,383 条（8.9%）。三层依据：原库地区标记 385、Wikidata 结构化字段 14,513、维基分类/正文推断 29,640；每条带「可信度 + 依据」标签 |
| 领域 | 维基原始分类归并到约 20 个桶；「分类缺失」单列（18,416 条，多为无正文条目），不与「其他」混淆 |
| 死因 | 5,403 条有归类（11.0%），其余为「未知」；**覆盖率低、样本有偏，只作探索** |
| 完整生平 | 29,972 人 / 约 4,170 万字 / 50 个懒加载分片；`data/` 合计约 122MB，首屏只下载 15.5MB 的 `starmap.js` |

地区是**落位参考值，不是国籍或籍贯结论**：优先取原库标记与 Wikidata 的 P27 国籍、P19 出生地所属国、P20 逝世地所属国，其后才是维基分类/正文的文本推断。
中心点取自 Natural Earth 110m 国家几何的**面积最大多边形质心**；同地多星按地理尺度分级散开，因此星点是「落在该地区附近」而非精确出生/逝世地。

## 地图合规说明

- 底图只用 **Natural Earth 110m `land`**（公有领域）的**海岸线剪影**：**不画任何国界、行政边界或争议地区标注**；177 国几何仅用于计算国家中心点，不参与绘制。
- **不调用任何在线地图服务、瓦片或 API**，运行时零外部请求（CDP 实测 `externalRequests=[]`）。
- 地区名称一律用规范中文表述：**中国台湾 / 中国香港 / 中国澳门**，三者均标为中国地区；科索沃等按中国官方立场不单列。
- 数据仅为公开讣告人物的推断地区，不含任何实时或个人位置数据。

## 地区补全（2026-11-05）

首版仅靠本地维基分类 / 摘要 / 正文推断，定位 61.2%，余下 38.8% 是「仅索引、无独立词条」条目——本地库确实没有正文、分类或摘要，不是程序漏读。

本次对这 18,975 人按中文标签批量查询 Wikidata 的 P27 / P19→P17 / P20→P17，并用 P570 逝世年校验同名歧义，补回 **14,513 人**，定位率升到 **91.1%**：

- 端点默认走 QLever 公共 Wikidata 镜像（官方 WDQS 在本网络下同一 IP 连续请求会握手卡死）；逐批缓存可断点续跑。
- 结果汇总落盘为 `starmap/data/wd_regions.json`（1.69MB）与 `qid_labels.json`，**之后生成与浏览都完全离线**。
- 剩余 4,383 人 Wikidata 无条目或无国籍字段，完整保留在名单与统计中，只是不落地图。
- 历史政权（苏联、中华民国、唐朝、卡扎尔王朝等）按现代地区落位并标注为参考，不作事实结论。

## 已知限制

- 地区是推断值：Wikidata 的国籍可能与出生地、旅居地、任职地不同；详情页标明依据与可信度，不应作为考据结论。
- 死因覆盖率仅 11.0%，享年为年份差粗算（±1 岁），两者都只作探索性分析。
- 名单默认渲染前 80 条，向下滚动自动续载；完整生平超 30,000 字者截断并给出提示。
- 等距圆柱投影下高纬度与南极会被拉宽，属示意底图，非测绘用途。
- 江山时序联动**暂不做**：本库主体仅 1976–2025 五十年，与长时段历史地图联动价值有限。
