# 驾鹤集 · 群星纪年（离线星图）

把 1973–2025 年 48,980 位逝者放进一张世界星图：拉动时间轴，当期星辰依次亮起；
点击星点或右侧名单看生平。和「江山时序」一样是**纯前端离线页**，`file://` 直开，
不联网、不起服务、不加载任何在线地图。

## 打开

- 从 `Bookshelf/开始阅读.html` 点「驾鹤集 · 群星纪年」卡片；或
- 直接双击本目录 `index.html`（建议 Chrome / Edge / Safari；首次若改过 JS，按 `Cmd+Shift+R` 强刷）。

## 能做什么

| 操作 | 说明 |
|---|---|
| 拖动底部时间轴 | 年 / 月 / 日三档切换；当期逝者在地图上依次点亮，右侧同步出名单 |
| ▶ 播放 | 自动推进；空格播放暂停，`←` `→` 逐格，`/` 聚焦搜索 |
| 点击星点 / 名单项 | 打开详情：生卒、享年、领域、推断地区、原始分类、摘要、维基链接（外部，需联网） |
| 领域 / 地区 / 搜索 / 仅已定位 | 组合筛选，地图与名单同步 |
| 地址栏深链 | `?t=2020&g=year`、`?t=2020-06&g=month`、`?t=2020-6-18&g=day`，可收藏或分享当前视图 |

时间轴下方青色直方图是该时间粒度的收录人数，年份刻度按真实年份定位。

## 数据口径（重要）

| 项 | 值 |
|---|---|
| 记录数 | **48,980**（`person` 表 49,157 条，剔除 `excluded=1` 的 177 条非人物） |
| 年份跨度 | 1973–2025（51 个年份；1973 仅 1 条种子记录、1974–1975 无记录，主体自 1976 年起） |
| 日期精度 | 42,636 条精确到日、750 条到月、5,771 条只到年。月/日档会把精度不足者列在提示里，需切回「年」档查看，不做假造日期 |
| 地区 | **推断值，不是事实结论**。库里 `region` 字段 49,157 条中仅 386 条有值，故按维基分类 / 摘要首句 / 正文首段加权投票推断；已定位 29,956 条（**61.2%**），其余 19,024 条无地理线索，不落地图但完整进名单 |
| 领域 | 由维基原始分类（8,678 种）归并到约 20 个桶；「分类缺失」单列，不与「其他」混淆 |

地区中心点取自 Natural Earth 110m 国家几何的**面积最大多边形质心**；同一地区的多颗星做散开处理，
按地理尺度分级控制半径，因此星点是「落在该地区附近」而非精确出生/逝世地。

## 地图合规说明

- 底图只用 **Natural Earth 110m `land`**（公有领域）的**海岸线剪影**：**不画任何国界、行政边界或争议地区标注**；177 国几何仅用于计算国家中心点，不参与绘制。
- **不调用任何在线地图服务、瓦片或 API**，页面不含任何 key，运行时零外部请求。
- 地区名称一律用规范中文表述：**中国台湾 / 中国香港 / 中国澳门**，三者均标为中国地区。
- 数据仅为公开讣告人物的推断国籍/地区，不含任何实时或个人位置数据。

## 文件与重建

```
驾鹤集星图/
  index.html          前端真源（CSS/JS 全内嵌；副本同步在 GitHub starmap/web/index.html）
  README.md           本文件
  data/starmap.js     生成物，约 15MB（window.JHSTAR）
```

`data/` 按 Bookshelf 既有约定**不进本地 git**（生成物可重生，走 QSync→NAS 备份；`.gitignore` 里有规则）。
数据变了或想重建，一条命令：

```bash
python3 ~/WorkBuddy/task/Project/jiaheji/starmap/build_starmap.py
```

脚本读 `data/jiaheji.db` + `raw` 正文，输出覆盖 `data/starmap.js`。
地理源固定在仓库 `starmap/geo/`（`land-110m.json` + `countries-110m.json`），
**生成过程不需要联网**；只有首次取这两个公有领域文件时用过一次公网。

## 已知限制

- 约 38.8% 记录无地理线索，不在地图上出现（名单完整）；这是中文维基「仅索引、无独立词条」条目的数据源上限，不是程序漏读。
- 「地区」是文本推断，会有人被归到旅居地/任职地；与定义性首句的一致性实测 98.4%，但不应作为考据结论使用。
- 名单默认渲染前 80 条，向下滚动自动续载。
- 等距圆柱投影下高纬度与南极会被拉宽，属示意底图，非测绘用途。
