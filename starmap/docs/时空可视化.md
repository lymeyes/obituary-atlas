# 群星纪年 · 时空可视化工程说明

> 面向维护者的复现文档。面向使用者的说明见 `docs/使用说明.md`（与 Bookshelf 内 README 同源）。
> 前端真源 `starmap/web/index.html`，数据生成器 `starmap/build_starmap.py`，地理源 `starmap/geo/`。

## 1. 目标与形态

把「只能按表格查数据库」的 4.9 万条人物档案，改造成**拉动时间轴看群星依次亮起**的时空可视化。
沿用「江山时序」的形态：单个 HTML + 一个内嵌数据 JS，`file://` 直开，零外部请求、无后端、无 API key。

| 层 | 文件 | 是否入 git |
|---|---|---|
| 前端真源 | `starmap/web/index.html`（CSS/JS 全内嵌） | ✅ |
| 运行副本 | `~/Obsidian/Bookshelf/驾鹤集星图/index.html` | Bookshelf 本地 git ✅ |
| 数据生成物 | `~/Obsidian/Bookshelf/驾鹤集星图/data/starmap.js`（约 15MB） | ❌ 生成物，QSync→NAS |
| 生成器 | `starmap/build_starmap.py` | ✅ |
| 地理源 | `starmap/geo/land-110m.json`、`countries-110m.json` | ✅ 小体积、可复现 |

## 2. 数据管线（`build_starmap.py`）

### 2.1 输入 / 输出

- 输入：`data/jiaheji.db` 的 `person`（49,157 行）+ `raw`（30,128 行维基正文），以及两个地理 JSON。
- 输出：一个 `window.JHSTAR` 对象，`<script src>` 直接加载（用 JS 而非 `fetch` 的 JSON，才能 `file://` 直开）。
- `cols` 字段给出列下标约定：`n,y,m,d,prec,by,age,reg,fld,cat,bio,wiki`；每行是数组而非对象，省掉 49k 次重复键名。

### 2.2 关键处理

| 环节 | 做法 | 原因 |
|---|---|---|
| 过滤 | `excluded=1` 的 177 条非人物不进星图 | 与 `reader/` 口径一致；原始数据不删 |
| 日期 | `parse_date()` 产出 `(y,m,d,prec)`，`prec` = 0 日 / 1 月 / 2 年 / 3 缺失 | 5,771 条只到年、750 条只到月；月/日档**不伪造日期**，另行提示「需在年档查看」 |
| 领域 | 复用 `reader/build_jiahe.py` 的 `FIELD_RULES`，把 8,678 种维基分类归到约 20 个桶 | 「分类缺失」单列，不与「其他」混淆（39% 记录本就无分类） |
| 地区 | **加权投票**：分类 3 分 / 摘要首句 3 分 / 正文首句 2 分 / 正文后段各 1 分；每个来源只贡献其最具体的一次命中 | 库里 `region` 仅 386 条有值（0.8%）。「首个命中即返回」会被后文旅居地误导；与定义性首句一致性实测 **98.4%** |
| 未定位 | `reg = -1`，不落地图但完整进名单与统计 | 19,024 条（38.8%）是「仅索引、无独立词条」，数据源本身无地理信息 |
| 中心点 | 从 `countries-110m.json` 取各国**面积最大多边形**的 shoelace 质心；小国/地区用内置备用坐标 | 避开飞地与海外领地（如美国不会被阿拉斯加拉偏）；129 个英文名全部匹配成功 |

### 2.3 陆地轮廓（合规核心）

`TopoJSON` 解码：arcs 是 delta 编码，配合 `transform.scale/translate` 还原经纬度；负 arc 下标表示反向。
`land_svg_path()` 把 `objects.land` 的每个 ring 用等距圆柱投影转成一条 SVG path。

- **只用 `land`（海岸线），不使用 `objects.countries` 的任何边界线**。
- `countries-110m.json` **只**用于算中心点，其 arcs 从不进入页面。
- 产物约 60KB，无国界、无行政边界、无争议地区标注。

## 3. 前端实现（`web/index.html`）

| 部件 | 实现 |
|---|---|
| 底图 | `<svg viewBox="0 0 1000 500">`：19 条经纬线 + 1 条陆地 path，`preserveAspectRatio="xMidYMid meet"` |
| 投影一致性 | Canvas 用同一 `proj()` 与 `min(w/W, h/H)` 等比映射 + 居中偏移，保证星点精确压在 SVG 上 |
| 双层 Canvas | 离屏 canvas 一次性画全部已定位者的极暗底纹（约 3 万点），主 canvas 只重绘当期星点 |
| 星点散开 | 确定性伪随机（按记录下标 hash，位置稳定）；半径 `min(1.5+√count×1.3, cap)`，`cap` 按地理尺度分 20°/8°/4.5° 三档 |
| 点亮动画 | 按记录日期顺序错峰 `t = i/N × min(2400, 320+N×1.9) ms`，星核 + 两层克制光晕 + 呼吸；选中态白圈 |
| 命中检测 | 当期星点线性扫描（≤2,200 点），hover tooltip、点击开详情 |
| 时间轴 | `range` + Canvas 直方图 + 按真实年份定位的刻度；年 53 格 / 月 636 格 / 日 19,358 格 |
| 播放 | 年 1000ms、月 340ms、日 170ms；空格 / ← → 快捷键 |
| 名单 | 每次只渲染 80 条，滚动到底续载，避免 2,200 条 DOM 卡顿 |
| 深链 | `?t=YYYY[-M[-D]]&g=year|month|day`，`history.replaceState` 在 `file://` 下加 try/catch |
| 调试接口 | `window.__STAR`（只读 state / stars / visible / date / jump），供 CDP 自动化验证 |

**首版踩过的坑**：星点抖动半径只有 16° 且光晕 `rad×3.4`，1,500 颗星糊成几团光斑。改为地理尺度分级 + 锐利星核后才呈现「繁星」。
年份刻度最初用 flex 等距排列，与实际时间位置不符，改为按 `pos` 绝对定位。

## 4. 合规设计（必须保持）

| 要求 | 落实 |
|---|---|
| 不使用境外地图服务 / 瓦片 / Mapbox / Leaflet+OSM | 页面**零外部请求**，无任何地图 API、无 key；CDP 实测 `externalRequests=[]` |
| 国界、台湾、南海诸岛不得错绘漏绘 | **不绘制任何国界或行政边界**；底图只有无政治属性的海岸线剪影；台湾/香港/澳门作为陆地自然出现且与中国同色 |
| 名称规范 | 地区表内即写为「中国台湾 / 中国香港 / 中国澳门」，`region_cn=1` 标记为中国地区 |
| 个人信息保护 | 只有公开讣告人物的推断国籍/地区，无实时位置、无个人行踪；全部本地存储 |
| 图例明示 | 页面左下角写明「无国界陆地剪影，仅作定位参考，不表示任何边界或归属；地区由公开文本推断，非事实结论」 |

> 若日后要换成带国界的精确底图，须改走合规白名单内的地图服务（如腾讯地图 GL JS）。
> 世界范围属海外渲染场景，需要自行申请 key 并联网，届时将失去当前的离线能力 —— 不建议。

## 6. 更新与重建

```bash
# 1) 数据库更新后，重建 15MB 数据（默认输出 Bookshelf/驾鹤集星图/data/）
python3 starmap/build_starmap.py --check     # 先看统计（覆盖率、地区分布、年份）
python3 starmap/build_starmap.py

# 2) 改前端后，把真源同步到运行副本
cp starmap/web/index.html ~/Obsidian/Bookshelf/驾鹤集星图/index.html
```

生成器**不需要联网**；`--out` 可指定其他输出目录。地理源若需升级，
从 `world-atlas@2` 的 `land-110m.json` / `countries-110m.json`（Natural Earth 派生，公有领域）替换 `geo/` 下两份即可。

## 7. 已知限制

- 38.8% 无地理线索者不落地图（名单完整），为中文维基数据源上限。
- `span` 为 1973–2025，但 1973 只有 1 条种子记录、1974–1975 为空，主体自 1976 年起；时间轴保留空档以免伪造连续性。
- 「地区」是文本推断，存在旅居地误判；与定义性首句一致性 98.4%，不可作考据结论。
- 等距圆柱投影高纬/南极被拉宽；示意底图，非测绘用途。
- 摘要仅 110 字，完整生平仍在原有 `阅读器-驾鹤集/` 与 Obsidian 笔记里；维基链接需联网打开。
