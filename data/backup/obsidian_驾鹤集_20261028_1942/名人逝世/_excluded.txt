# 剔除名单（一行一个姓名，与笔记文件名一致，不带 .md）
# 作用：名单里的姓名既不生成笔记，也不出现在 HTML 列表/日历中。
# 用法：
#   1) 在下面加一行姓名，例如：某某某
#   2) 双击同目录的「重建.command」（或终端运行 python3 _generate.py）
#   3) 刷新 HTML 即可看到此人已被移除
# 兼容：直接在 Obsidian 里删掉某人的 .md 笔记，再重建，也会自动剔除并记录到本文件末尾。
# 恢复：删掉对应行（或把笔记文件放回），重建即可。
# 注意：以 # 开头为注释，空行忽略。
# ============================================================
